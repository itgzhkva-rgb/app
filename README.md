# Своя неделя
Личное еженедельное планирование на русском языке: шесть этапов, таймер, задачи, рефлексия, история и резервные копии.

## Запуск
Требуется Node.js 20 или новее. В каталоге проекта выполните `npm start`. Сервер слушает порт 3000 (или переменную PORT). Внешние зависимости не нужны.

Данные сохраняются в localStorage текущего браузера. Нет регистрации, сервера данных или синхронизации. Очистка браузера удаляет записи; регулярно экспортируйте JSON через историю недель. Импорт добавляет отсутствующие сессии, не перезаписывая существующие. Ведущий не получает ответы участников.

Таймер продолжает считать время в фоне, но звуковой сигнал зависит от браузера. Переходы между этапами ручные, при переходе таймер ставится на паузу.

Для использования участниками нужно разместить приложение на HTTPS-хостинге. Файлы index.html, style.css, app.js и document.js могут обслуживаться статическим хостингом; server.js нужен только для локального запуска.

## Выгрузка и печать
Сессия и вся история выгружаются в настоящий Word (.docx), формируемый локально без отправки личных данных на сервер. Каждая сессия истории начинается с новой страницы. «Печать / сохранить PDF» формирует полный отчёт с итогами прошлой недели и следующим планом; для PDF выберите соответствующее назначение в диалоге печати. JSON остаётся резервной копией для восстановления через импорт. Импорт Word не поддерживается.
